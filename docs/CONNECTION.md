# 처음 대화 연결하기 · 모델 고르기

[서버 플러그인과 사용량 확장](DESKTOP.md)을 모두 설치하고, SillyTavern 서버 재시작과 브라우저 새로고침까지 끝난 상태에서 진행합니다. Termux 설치자는 [Termux 안내](TERMUX.md)를 먼저 따라 주세요.

## 1. 사용량 팝업 열기

SillyTavern의 확장 설정에서 **Codex Usage**를 누릅니다. 마법봉 메뉴의 **Codex Usage** 또는 화면에 떠 있는 Codex 잔량 표시를 눌러도 열립니다.

- **ChatGPT / CLI 연결됨**이면 모델을 선택할 수 있습니다.
- **로그인 필요**이면 SillyTavern 서버를 실행하는 환경에서 `codex login`을 완료하세요.
- **연결 확인 필요**나 서버 설치 안내가 나오면 [문제 해결](TROUBLESHOOTING.md)을 확인하세요.

## 2. 모델 선택하기

**모델** 목록에서 원하는 모델 행을 누르면 SillyTavern API 설정에 주소와 모델이 즉시 입력됩니다. API 키 없이 SillyTavern의 연결 프로필로 저장하세요. Usage의 모델 선택은 서버 공통 기본값을 바꾸지 않습니다.

목록이 비어 있다면 CLI 로그인 확인 후 **모델 옆 새로고침 아이콘**을 누르세요. 서버 시작 때 한 번 조회하고 이후에는 이 아이콘을 눌렀을 때만 다시 조회합니다. 잔량 새로고침과 팝업 열기는 모델을 재조회하지 않습니다. 목록 갱신은 현재 선택과 작성 중인 모델 ID를 바꾸지 않습니다.

목록에 없는 모델은 **설정 → 모델 ID 직접 입력 → 연결에 입력**으로 사용할 수 있습니다. CLI 목록은 카탈로그이므로 실제 접근 가능 여부는 해당 계정의 대화 요청 때 확인됩니다. Termux도 같은 방식이며 이전 `codex-default` 선택도 CLI 기본 모델 별칭으로 계속 사용할 수 있습니다.

## 3. 연결 프로필별 추론 설정하기

Usage **설정 → 연결 프로필별 추론 설정**에서 저장한 Codex 연결 프로필을 선택합니다. 해당 프로필을 SillyTavern에도 불러오고, 프로필의 모델을 읽기 전용으로 표시합니다.

**추론 단계**를 선택하고 **이 프로필에 저장**을 누르세요. 각 사용자가 자신의 프로필에 저장하므로 SillyTavern admin 계정일 필요는 없습니다. 같은 모델·같은 프리셋을 쓰는 두 프로필에도 서로 다른 단계를 저장할 수 있습니다.

프로필을 전환하면 저장한 추론이 다음 대화에 적용됩니다. 이미 생성 중인 요청에는 영향을 주지 않습니다. **기본값 사용**이나 저장값 없는 프로필은 브리지 기본값을 사용합니다. 프로필 이름을 바꿔도 유지되며, 모델을 변경했다면 추론도 다시 저장하세요.

설정은 SillyTavern 사용자 설정의 해당 연결 프로필에 보관됩니다. 이 브리지를 사용하는 Connection Manager 보조 요청도 지정한 프로필의 추론을 사용합니다.

## 4. SillyTavern 연결 확인하기

모델 행을 누르거나 상태 카드의 **연결**을 누르면 다음 값이 API 설정에 입력됩니다. 입력 후 SillyTavern **API 연결 화면**에서 **연결**을 누르고 필요하면 연결 프로필을 저장하세요. 팝업은 자동으로 닫히지 않으므로 닫기 아이콘으로 닫을 수 있습니다.

| 항목 | 값 |
| --- | --- |
| API 종류 | Chat Completion |
| Chat Completion Source | Custom (OpenAI-compatible) |
| URL | `http://127.0.0.1:7861/v1` |
| Model | 누른 모델 행 또는 직접 입력한 모델 ID |
| API Key | 비워 두기 |

브리지 포트를 바꿨다면 팝업의 새 주소를 사용합니다. 기존 Custom 연결에 API 키·추가 헤더·추가 요청 본문 설정이 남아 있다면 이 연결에 맞게 정리하세요.

연결 프로필을 저장한 뒤에는 Usage 또는 SillyTavern에서 프로필을 전환해 사용하면 됩니다. Usage의 현재 적용 영역에서 프로필·모델·추론을 확인할 수 있습니다. 모델 행을 눌러 프로필과 다른 모델로 바꿨다면 SillyTavern에서 프로필도 업데이트하세요.

## 5. 짧은 대화로 확인하기

평소처럼 캐릭터 채팅을 열고 짧은 메시지를 한 번 보내 보세요. 답변이 생성되면 사용량 팝업의 **요청별 토큰 기록**에서 완료 상태와 입력·출력 토큰을 확인합니다. CLI가 세부 토큰을 제공하지 않으면 `—`로 표시합니다.

캐릭터·프리셋·로어북·컨텍스트 설정은 SillyTavern이 만든 최종 메시지에 반영되는 범위를 사용합니다. 매 요청은 독립 세션이며 SillyTavern이 보낸 대화 이력을 함께 전달합니다.

## 사용량 표시 읽기

| 표시 | 의미 |
| --- | --- |
| 5시간·주간 `% 남음` | CLI가 제공한 계정 잔량. 같은 계정의 다른 Codex 사용도 영향을 줄 수 있음 |
| 리셋 시각 | CLI가 제공한 값을 현재 브라우저의 현지 시각으로 표시 |
| `0%` | CLI가 실제로 남은 잔량을 0으로 제공 |
| `미제공` | 해당 기간·토큰 항목을 CLI가 제공하지 않음 |
| `조회 불가` | 조회 실패 또는 올바른 수치를 받지 못함 |
| 이 브리지의 토큰 | 이 브리지를 거친 요청만 합산. 계정 전체 토큰 합계가 아님 |

상태 카드의 **새로고침 아이콘**은 잔량·요청 기록을 갱신합니다. **모델 옆 새로고침 아이콘**은 모델 목록을 다시 조회합니다. 두 버튼의 역할은 다릅니다.

화면에 떠 있는 작은 잔량 표시는 누르면 팝업이 열립니다. 끌어서 위치를 옮길 수 있고, 팝업 **설정**의 **화면에 잔량 표시** 체크를 끄면 숨길 수 있습니다. 표시 여부·위치는 해당 브라우저에 저장합니다.

## 사용량 기록 초기화

팝업 **설정 → 사용량 기록 초기화**에서 확인 후 이 브리지의 요청별 기록·토큰 합계를 지울 수 있습니다. 공식 계정 잔량이나 모델·추론 설정은 바뀌지 않습니다. 저장 권한과 마찬가지로 SillyTavern admin 계정만 사용할 수 있으며 사용자 계정 기능을 쓰지 않으면 누구나 사용할 수 있습니다. 생성 중이던 요청이 나중에 완료되면 새 기록으로 추가될 수 있습니다.

플로팅 **기간**은 5h·7d·둘 다 중 선택하며 마법봉 숫자에도 적용됩니다. **위치**는 네 모서리 중 선택할 수 있고 표시 설정은 해당 브라우저에 저장됩니다.

## 미리 알아둘 제한

**Temperature·Top-p는 Codex CLI에 적용되지 않습니다. 최대 토큰은 답변 길이 안내이며 강제 상한이 아닙니다.** 텍스트 전용으로 이미지·오디오·파일 첨부와 도구 호출은 지원하지 않습니다. 자세한 범위는 [README](../README.md#알아둘-점)를 확인하세요.
