# 처음 대화 연결하기 · 모델 고르기

[서버 플러그인과 사용량 확장](DESKTOP.md)을 모두 설치하고, SillyTavern 서버 재시작과 브라우저 새로고침까지 끝난 상태에서 진행합니다. 터먹스 설치자는 [터먹스 안내](TERMUX.md)를 먼저 따라 주세요.

## 1. 사용량 팝업 열기

SillyTavern의 확장 설정에서 **Codex Bridge · 사용량**을 누릅니다. 마법봉 메뉴의 **Codex 사용량** 또는 화면에 떠 있는 Codex 잔량 표시를 눌러도 열립니다.

- **ChatGPT / CLI 연결됨**이면 모델을 선택할 수 있습니다.
- **로그인 필요**이면 SillyTavern 서버를 실행하는 환경에서 `codex login`을 완료하세요.
- **연결 확인 필요**나 서버 설치 안내가 나오면 [문제 해결](TROUBLESHOOTING.md)을 확인하세요.

## 2. 모델 선택하기

**사용 가능한 모델**에서 원하는 모델을 누릅니다. 선택한 모델 ID가 아래 **선택 모델 · 직접 입력** 칸에 들어갑니다.

목록이 비어 있다면 CLI 로그인 상태를 확인하고 **모델 새로고침**을 누르세요. 목록은 서버 시작 때 한 번 조회하고, 이후에는 이 버튼을 눌렀을 때만 CLI에 다시 조회합니다. 팝업을 열거나 잔량을 갱신해도 모델을 다시 조회하지 않습니다.

목록에 없는 모델 ID를 알고 있다면 직접 입력할 수 있습니다. 목록 갱신으로 직접 입력하거나 선택한 모델을 다른 것으로 바꾸지 않습니다. 목록은 CLI 카탈로그이므로 실제로 사용할 수 있는지는 해당 계정의 대화 요청 때 확인됩니다.

터먹스 exec 모드에서는 자동 모델 목록 대신 **Codex CLI 기본 모델**(`codex-default`)을 선택하거나 모델 ID를 직접 입력합니다.

## 3. 추론 단계 설정하기

**추론 단계**에서 선택 모델이 제공하는 단계를 고릅니다. 지원 단계는 모델마다 다를 수 있습니다. 어느 단계를 쓸지 정하지 않았다면 표시된 설정으로 먼저 짧은 대화를 시도해 보세요.

**모델·추론 설정 저장**을 누르면 서버 공통 설정으로 저장합니다. 이 버튼은 SillyTavern 서버 관리자만 사용할 수 있습니다. 저장한 추론 단계는 브리지 요청에 적용되며, 현재 대화 연결의 모델을 바꾸려면 다음 단계의 **대화 연결에 입력**도 눌러야 합니다.

## 4. 대화 연결 화면에 입력하기

**대화 연결에 입력**을 누릅니다. SillyTavern의 API 설정에 연결 방식·주소·선택 모델을 채워 넣고 팝업이 닫힙니다.

이제 SillyTavern의 **API 연결 화면**을 열어 다음을 확인하고 **연결**을 누르세요. 팝업에서 자동 입력한 것만으로 연결 버튼까지 누른 상태가 되는 것은 아닙니다.

| 항목 | 값 |
| --- | --- |
| API 종류 | Chat Completion |
| Chat Completion Source | Custom (OpenAI-compatible) |
| URL | `http://127.0.0.1:7861/v1` |
| Model | 팝업에서 선택한 모델 ID |
| API Key | 비워 두기 |

브리지 포트를 따로 바꿨다면 팝업에 표시된 새 주소를 사용합니다. 기존 Custom 연결의 API 키·추가 헤더·추가 요청 본문 설정이 남아 있다면 이 연결에 맞게 정리하세요.

휴대폰에서 PC의 SillyTavern에 접속 중이어도 URL은 `127.0.0.1`로 둡니다. 이 주소는 브라우저가 아니라 **SillyTavern 서버가 실행되는 기기**를 가리킵니다.

## 5. 짧은 대화로 확인하기

평소처럼 캐릭터 채팅을 열고 짧은 메시지를 한 번 보내 보세요. 답변이 생성되면 사용량 팝업의 **요청별 토큰 기록**에서 완료 상태와 입력·출력 토큰을 확인합니다. CLI가 세부 토큰을 제공하지 않으면 `—`로 표시합니다.

캐릭터·프리셋·로어북·컨텍스트 설정은 SillyTavern이 만든 최종 메시지에 반영되는 범위를 사용합니다. 매 요청은 독립 세션이며 SillyTavern이 보낸 대화 이력을 함께 전달합니다.

## 사용량 표시 읽기

| 표시 | 의미 |
| --- | --- |
| 5시간·주간 `% 남음` | CLI가 제공한 계정 잔량. 같은 계정의 다른 Codex 사용도 영향을 줄 수 있음 |
| 리셋 시각 | CLI가 제공한 값을 현재 브라우저의 현지 시각으로 표시 |
| `0% 남음` | CLI가 실제로 남은 잔량을 0으로 제공 |
| `미제공` | 해당 기간·토큰 항목을 CLI가 제공하지 않음 |
| `조회 불가` | 조회 실패 또는 올바른 수치를 받지 못함 |
| 이 브리지의 토큰 | 이 브리지를 거친 요청만 합산. 계정 전체 토큰 합계가 아님 |

상단 **새로고침**은 잔량·요청 기록을 갱신합니다. **모델 새로고침**은 모델 목록을 다시 조회합니다. 두 버튼의 역할은 다릅니다.

화면에 떠 있는 작은 잔량 표시는 누르면 팝업이 열립니다. 왼쪽 손잡이를 끌면 위치를 옮길 수 있고, 팝업 아래 **플로팅 잔량** 체크를 끄면 숨길 수 있습니다. 표시 여부·위치는 해당 브라우저에 저장합니다.

## 미리 알아둘 제한

**Temperature·Top-p는 Codex CLI에 적용되지 않습니다. 최대 토큰은 답변 길이 안내이며 강제 상한이 아닙니다.** 텍스트 전용으로 이미지·오디오·파일 첨부와 도구 호출은 지원하지 않습니다. 자세한 범위는 [README](../README.md#제한)를 확인하세요.
